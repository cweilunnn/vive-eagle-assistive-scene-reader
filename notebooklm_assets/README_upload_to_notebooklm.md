# NotebookLM 使用說明

## 建議上傳的來源檔案

請把以下檔案上傳到 NotebookLM：

1. `project_brief_for_notebooklm.md`
   - 這是專題的主要介紹資料。

2. `smart_glasses_life_system_diagram.md`
   - 這是智慧眼鏡科技對生活的系統關係圖文字版。

3. `smart_glasses_life_system_diagram.svg`
   - 這是可放進簡報的系統關係圖視覺版。

4. `screenshots/01_app_result_large_text.png`
   - App Demo 畫面：街景照片與大字簡潔結果。

5. `screenshots/02_app_full_gemini_response.png`
   - App Demo 畫面：Gemini 完整 JSON 回覆。

6. `screenshots/03_test_street_safe.png`
   - 內建測試街景：安全通行情境。

7. `screenshots/04_test_street_scooter.png`
   - 內建測試街景：右側機車情境。

## 在 NotebookLM 裡要貼的 Prompt

請打開 `notebooklm_prompt.md`，把全文貼到 NotebookLM 的提問欄。

## 建議產出方向

請讓 NotebookLM 幫你產出：

- 10 到 12 張投影片大綱
- 每張投影片標題
- 每張投影片 3 到 5 個重點
- 每張投影片講稿
- 圖片放置建議
- 1 分鐘總結講稿

## 簡報語氣提醒

這份簡報是給國中生看的，所以請 NotebookLM：

- 用簡單生活例子說明。
- 不要把 AI 講得像魔法。
- 不要保證系統一定安全。
- 要誠實說目前還沒接上真正眼鏡拍照來源。
- 要強調這是輔助提醒，不是取代人的判斷。

## 可以再讓 Codex 幫你做的事

你可以再請 Codex 做：

- 把 NotebookLM 產出的投影片大綱整理成正式講稿。
- 幫你把簡報文字縮短到每頁不超過 5 行。
- 幫你把內容改成更像國中生會講的口吻。
- 幫你生成 PowerPoint 檔。
- 幫你做一頁 Demo 操作流程圖。
- 幫你做 Q&A 題庫，例如老師可能會問什麼。
- 幫你把 App Demo 再跑一次並更新截圖。
