# NotebookLM 使用說明：因果關係圖版本

你這次要的是「因果關係圖」，不是一般系統流程圖。

請優先使用以下新版檔案：

1. `notebooklm_prompt_causal_diagram.md`
   - 直接貼給 NotebookLM 的 prompt。
   - 已經要求 NotebookLM 做正相關、負相關、時間延遲、強化迴路和平衡迴路。

2. `smart_glasses_causal_loop_diagram.md`
   - 因果關係圖文字版。
   - 裡面有 Mermaid 圖、R1/R2/B1/B2 迴路解釋。

3. `smart_glasses_causal_loop_diagram.svg`
   - 可直接放進簡報的因果關係圖視覺版。
   - 圖上有 `+`、`-`、`Delay`、R1、R2、B1、B2。

4. `project_brief_for_notebooklm.md`
   - 專題背景與介紹。

5. `screenshots/`
   - App demo 截圖與街景測試圖。

## 不建議使用的舊圖

如果你要的是因果關係圖，請不要優先使用：

- `smart_glasses_life_system_diagram.md`
- `smart_glasses_life_system_diagram.svg`
- `notebooklm_prompt.md`

這些是舊版「流程/系統關係圖」，不是因果回饋圖。

## 可以直接貼給 NotebookLM 的一句話

請根據我上傳的資料，幫我做一份給國中生看的簡報。請特別使用 `smart_glasses_causal_loop_diagram.svg` 作為「智慧眼鏡科技對生活的因果關係圖」，並解釋圖中的 `+`、`-`、`Delay`、R1、R2、B1、B2。請不要把它改成普通流程圖。
